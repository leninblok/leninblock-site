# Публикация и передача проекта

Проверено 23 ноября 2026 года (Москва).

## Размещение

- Исходники сайта: https://github.com/leninblok/leninblock-site, ветка `main`.
- Vercel подключён владельцем через GitHub. Push в `main` запускает production deploy; переменных окружения для сайта не требуется.
- Основной домен https://leninblock.ru/kruzhok отвечает HTTP 200 по HTTPS. NS Vercel настроены владельцем в REG.RU.
- https://www.leninblock.ru/kruzhok отвечает HTTP 307 с перенаправлением на основной домен. Этот ответ формирует Vercel до правила Next.js 308.
- Резервный адрес: https://leninblock-site.vercel.app.
- GitHub Actions сайта проверяет lint, production build, TypeScript и браузерные тесты. Локальные проверки используют отдельный production-сервер на порту 3100.

Vercel CLI не авторизован. Для текущей публикации это не требуется: используется уже подключённая Git-интеграция. Анонимный временный проект не создавался.

## Кружок

Репозиторий приложения https://github.com/leninblok/floating-camera открыт по указанию владельца. На странице Кружка — один основной файл для определённой ОС: универсальный Mac DMG (Apple Silicon и Intel) или Windows x64 EXE. «Другие версии» позволяет выбрать вручную. Установщики хранятся в публичном GitHub Release v1.1.0, вход для скачивания не нужен.

Универсальная сборка и ручной workflow `Publish universal macOS installer` добавлены в репозиторий приложения. Workflow проверяет тесты, обе архитектуры каждого Mach-O файла и целостность DMG, публикует файл и добавляет его SHA-256 в SHA256SUMS. Подпись Apple Developer ID и нотариализация не добавлены: эта версия остаётся неподписанной, что указано в раскрывающейся инструкции установки.

Видео автора оптимизировано до 303 КБ, оригинальный MOV сохранён локально и исключён из Git. Камера посетителя используется только в браузере после явного согласия, без микрофона, записи и загрузки на сервер.
