# Публикация и передача проекта

Проверено 23 ноября 2026 года (Москва).

## Размещение

- Исходники сайта: https://github.com/leninblok/leninblock-site, ветка `main`.
- Vercel подключён владельцем через GitHub. Push в `main` запускает production deploy; переменных окружения для сайта не требуется.
- Основной домен https://leninblock.ru/kruzhok отвечает HTTP 200 по HTTPS. NS Vercel настроены владельцем в REG.RU.
- https://www.leninblock.ru/kruzhok отвечает HTTP 307 с перенаправлением на основной домен. Этот ответ формирует Vercel до правила Next.js 308.
- Резервный адрес: https://leninblock-site.vercel.app.
- GitHub Actions сайта проверяет lint, production build, TypeScript и браузерные тесты. Локальные проверки используют отдельный production-сервер на порту 3100.

Vercel CLI не авторизован. Для текущей публикации это не требуется: используется уже подключённая Git-интеграция. Анонимный временный проект не создавался.

## Кружок

Репозиторий приложения https://github.com/leninblok/floating-camera открыт по указанию владельца. На странице Кружка — один основной файл для определённой ОС: универсальный Mac DMG (Apple Silicon и Intel) или Windows x64 EXE. Прямая текстовая ссылка под основной кнопкой скачивает другую ОС. Установщики хранятся в публичном GitHub Release v1.2.0, вход для скачивания не нужен.

Приложение переведено с Electron на Tauri 2. Исходники опубликованы в `main`; старый релиз v1.1.0 сохранён. Установщики v1.2.0:

| --- | ---: | --- |
| `Kruzhok-1.2.0-mac-universal.dmg` | 8 253 631 | `9bc7817dc652f6f1b8512493a10755182a731c565c830e5e6ad6a14678c47a04` |
| `Kruzhok-1.2.0-windows-x64-Setup.exe` | 1 255 526 | `d171e9b5dca289f14455794da0c5fd913de3ade6d5df82de31ad5138a9142f3f` |

Оба установщика проверены GitHub Actions на Mac и Windows с искусственной камерой. DMG дополнительно запущен локально; проверены arm64/x86_64 и целостность ad-hoc подписи. Проверки включают первый кадр, все формы и размеры, прозрачные углы, фокус, контур, отражение, положение поверх окон и сохранение настроек. npm audit и RustSec audit по целевым Mac/Windows прошли. В обоих репозиториях настроены Dependabot, security updates и регулярные проверки зависимостей. В приложении дополнительно проверяется Cargo.lock.

Mac имеет техническую ad-hoc подпись, пока без Developer ID и нотариального заверения. У Windows-сборки пока нет сертификата издателя. Инструкции первого запуска размещены в GitHub Release. Для устранения системных предупреждений нужны сертификаты владельца; доступ к Apple Developer/Windows signing не предоставлен. Физическую камеру, системный запрос разрешения и несколько мониторов с разным масштабом нужно дополнительно проверить на целевых компьютерах. Автоматические проверки не обращаются к физическим камерам.

Windows использует системный WebView2; если он отсутствует, установщик загружает runtime у Microsoft. Поэтому маленький EXE не означает отсутствие зависимости от установленного WebView2.

На сайте используются общие с приложением `renderer.js`, CSS и `src/native-layout.js`; для WKWebView/Safari без CSS corner-shape добавлена SVG-маска superellipse. Полные 26 браузерных тестов прошли перед публикацией. Vercel опубликовал commit `e37f5c2`, ссылки проверены анонимно (HTTP 200), SHA256SUMS совпал с локальными файлами.


Видео автора оптимизировано до 303 КБ, оригинальный MOV сохранён локально и исключён из Git. Страница использует оригинальный renderer и стили приложения, 30 исходных функций геометрии/анимаций и браузерный адаптер окна. Все параметры размещены под скачиванием, контекстного меню нет. Реализованы исходные формы, пропорции, наборы размеров, фокус, оформление, загрузка и перемещение. Настройки сохраняются в браузере.

Камера запрашивается автоматически; до разрешения и при отказе доступно видео автора. Микрофон, запись и загрузка изображения не используются. Разрешённый iframe runtime ограничен SAMEORIGIN; остальные страницы сохраняют DENY. Числовой эталон получен исполнением настоящего приложения, renderer и CSS дополнительно проверяются по SHA-256. Границы браузерной реализации и команды синхронизации описаны в README.
