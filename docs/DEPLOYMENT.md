# Публикация и передача проекта

Проверено 23 ноября 2026 года (Москва).

## Размещение

- Исходники сайта: https://github.com/leninblok/leninblock-site, ветка `main`.
- Vercel подключён владельцем через GitHub. Push в `main` запускает production deploy; переменных окружения для сайта не требуется.
- Основной домен https://leninblock.ru/kruzhok отвечает HTTP 200 по HTTPS. NS Vercel настроены владельцем в REG.RU.
- https://www.leninblock.ru/kruzhok отвечает HTTP 307 с перенаправлением на основной домен. Этот ответ формирует Vercel до правила Next.js 308.
- Резервный адрес: https://leninblock-site.vercel.app.
- GitHub Actions сайта проверяет lint, production build, TypeScript и браузерные тесты. Локальные проверки используют отдельный production-сервер на порту 3100.

Vercel CLI не авторизован. Для текущей публикации это не требуется: используется уже подключённая Git-интеграция. Анонимный временный проект не создавался.

## Кружок

Репозиторий приложения https://github.com/leninblok/floating-camera открыт по указанию владельца. На странице Кружка — один основной файл для определённой ОС: универсальный Mac DMG (Apple Silicon и Intel) или Windows x64 EXE. Прямая текстовая ссылка под основной кнопкой скачивает другую ОС. Установщики хранятся в публичном GitHub Release v1.1.0, вход для скачивания не нужен.

Универсальная сборка и ручной workflow `Publish universal macOS installer` добавлены в репозиторий приложения. Workflow проверяет тесты, обе архитектуры каждого Mach-O файла и целостность DMG, публикует файл и добавляет его SHA-256 в SHA256SUMS. Подпись Apple Developer ID и нотариализация не добавлены: эта версия остаётся неподписанной, что указано в описании GitHub Release. По просьбе владельца инструкция установки, версия и GitHub убраны со страницы продукта.

Видео автора оптимизировано до 303 КБ, оригинальный MOV сохранён локально и исключён из Git. Страница использует оригинальный renderer и стили приложения, 30 исходных функций геометрии/анимаций и браузерный адаптер окна. Все параметры размещены под скачиванием, контекстного меню нет. Реализованы исходные формы, пропорции, наборы размеров, фокус, оформление, загрузка и перемещение. Настройки сохраняются в браузере.

Камера запрашивается автоматически; до разрешения и при отказе доступно видео автора. Микрофон, запись и загрузка изображения не используются. Разрешённый iframe runtime ограничен SAMEORIGIN; остальные страницы сохраняют DENY. Числовой эталон получен исполнением настоящего приложения, renderer и CSS дополнительно проверяются по SHA-256. Границы браузерной реализации и команды синхронизации описаны в README.
