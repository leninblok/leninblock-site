## Действия владельца для постоянного размещения

1. Войти в Vercel (`npx vercel login`) или установить и подключить Vercel в Codex.
2. В Vercel проверить, не привязан ли `leninblock.ru` к существующему сайту. Не заменять существующий проект без проверки.
3. **Add New → Project → Import Git Repository**: выбрать `leninblok/leninblock-site`, Next.js, корень `./`, Node.js 24.x, production branch `main`. Нажать Deploy. Переменные окружения не нужны.
4. Дождаться Ready, проверить страницы на выданном `*.vercel.app`.
5. **Settings → Domains → Add**: добавить `leninblock.ru` и `www.leninblock.ru`. Для www включить redirect на домен без www.
6. Скопировать показанные Vercel записи DNS. В кабинете регистратора открыть зону `leninblock.ru`, внести именно эти значения, убрать только конфликтующие записи для этих же имён. NS/MX и почтовые TXT не менять.
7. Дождаться Valid Configuration и сертификата. Проверить `curl -I https://leninblock.ru/`, `/kruzhok`, `/bible`; `curl -I https://leninblock.ru/play` должен вернуть 307 с Location `https://www.wherefrombible.ru/`. Для `www.leninblock.ru` ожидается 308 на основной адрес.
