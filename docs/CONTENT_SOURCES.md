## Кружок

При первоначальном обследовании `leninblok/floating-camera` был приватным. 23 ноября 2026 года по явному указанию владельца репозиторий открыт. Публичность репозитория и релиза v1.1.0 проверена без авторизации.
README и код `main.js` / `renderer.js` подтверждают:

- камера поверх других окон, перемещение между мониторами;
- круг, прямоугольник, пропорции 1:1, 4:5, 9:16;
- выбор камеры, размера, контура, тени, отражение;
- увеличение по двойному клику и сохранение настроек;
- запись экрана ведётся другим приложением.

В публичном релизе v1.1.0 есть DMG для macOS arm64 и x64, EXE для Windows x64 и SHA256SUMS. В описании релиза прямо указано отсутствие цифровой подписи издателя. На страницу добавлены прямые ссылки на эти три файла и инструкции установки.

Проверка распространения: начата анонимная загрузка всех трёх бинарников; получены бинарные данные вместо HTML. Для обоих DMG отдельными диапазонными запросами проверен UDIF trailer (`koly`), для Windows — PE/NSIS-заголовки. SHA256SUMS скачан публично, значения совпадают с digest метаданных GitHub Release. Полные файлы через медленное соединение не загружались, их SHA-256 локально не пересчитывались. Установщики не запускались, подпись на реальных приложениях и установка на чистых macOS/Windows не проверялись. Страница не обещает запуск без системных предупреждений.

Реальных разрешённых скриншотов и видео в дереве репозитория нет. Обложка на сайте — типографическая композиция, не демонстрация интерфейса. TODO: получить у владельца короткую запись реальной работы программы и добавить её на /kruzhok.

## Подпись macOS

Официальная [инструкция Apple](https://support.apple.com/en-us/102445), проверенная при реализации: для распространения вне App Store macOS проверяет Developer ID и нотариализацию; неподписанные сборки могут блокироваться Gatekeeper. Обход защит на компьютере пользователя не выполнялся. Перед публикацией установщиков нужны проверка подписи (`codesign`), оценка Gatekeeper (`spctl`) и нотариализации (`xcrun stapler validate`) на реальных файлах.
