# Проверенные факты и материалы

Обследование начато 22 ноября 2026 года. В репозитории сайта нет исходников продуктов.

## Кружок

При первоначальном обследовании `leninblok/floating-camera` был приватным. 23 ноября 2026 года по явному указанию владельца репозиторий открыт. Публичность репозитория и релиза v1.1.0 проверена без авторизации.
README и код `main.js` / `renderer.js` подтверждают:

- камера поверх других окон, перемещение между мониторами;
- круг, прямоугольник, пропорции 1:1, 4:5, 9:16;
- выбор камеры, размера, контура, тени, отражение;
- увеличение по двойному клику и сохранение настроек;
- запись экрана ведётся другим приложением.

В публичном релизе v1.1.0 есть DMG для macOS arm64 и x64, EXE для Windows x64 и SHA256SUMS. В описании релиза прямо указано отсутствие цифровой подписи издателя. Первоначально на странице были ссылки на три отдельных установщика. Теперь основная версия для Mac универсальная, Windows x64 сохранён.

Проверка распространения: начата анонимная загрузка всех трёх бинарников; получены бинарные данные вместо HTML. Для обоих DMG отдельными диапазонными запросами проверен UDIF trailer (`koly`), для Windows — PE/NSIS-заголовки. SHA256SUMS скачан публично, значения совпадают с digest метаданных GitHub Release. Полные файлы через медленное соединение не загружались, их SHA-256 локально не пересчитывались. Установщики не запускались, подпись на реальных приложениях и установка на чистых macOS/Windows не проверялись. Страница не обещает запуск без системных предупреждений.

23 ноября владелец предоставил `видео.mov` для страницы Кружка. Из него сделан восьмисекундный квадратный MP4 (303 КБ) и JPEG-постер (35 КБ), без звука и метаданных местоположения. Это видео автора для браузерного интерактивного примера, не запись интерфейса настольного приложения.

Добавлен универсальный macOS DMG. Локальная сборка проверена `lipo`: все 14 Mach-O файлов содержат arm64 и x86_64. `hdiutil verify` прошёл; из смонтированного образа Electron runtime запущен под arm64 и x86_64 через Rosetta. `app.asar` совпадает с исходной версией 1.1.0; 42 модульных теста и Electron smoke с искусственной камерой прошли. Чистая установка Windows и подпись Apple Developer ID не проверены/не добавлены. Для публикации используется ручной GitHub Actions workflow с теми же проверками архитектур и образа; финальная SHA-256 хранится в SHA256SUMS релиза. Публикация через [успешную облачную сборку](https://github.com/leninblok/floating-camera/actions/runs/45166555891): 226 043 973 байта, SHA-256 `8b1da7e0564cd1487ee67b941fd9b59c4b8a558325f9e6eddffb5fd90a8f3ab3`. Контрольная сумма совпадает с digest GitHub. Анонимный диапазонный запрос проверяет UDIF trailer нового опубликованного файла.

## Подпись macOS

Официальная [инструкция Apple](https://support.apple.com/en-us/102445), проверенная при реализации: для распространения вне App Store macOS проверяет Developer ID и нотариализацию; неподписанные сборки могут блокироваться Gatekeeper. Обход защит на компьютере пользователя не выполнялся. Перед публикацией установщиков нужны проверка подписи (`codesign`), оценка Gatekeeper (`spctl`) и нотариализации (`xcrun stapler validate`) на реальных файлах.
