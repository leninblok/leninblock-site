## Подпись macOS

Официальная [инструкция Apple](https://support.apple.com/en-us/102445), проверенная при реализации: для распространения вне App Store macOS проверяет Developer ID и нотариализацию; неподписанные сборки могут блокироваться Gatekeeper. Обход защит на компьютере пользователя не выполнялся. Перед публикацией установщиков нужны проверка подписи (`codesign`), оценка Gatekeeper (`spctl`) и нотариализации (`xcrun stapler validate`) на реальных файлах.
