# Проверка результата

Проверено 23 ноября 2026 года (Москва). Next.js 16.4.6, Node.js 20.19.6 локально, Chromium 156 через Playwright 1.65.1. Для CI настроен Node.js 24.

## Пройдено

- `npm ci --offline --no-audit --no-fund` с локальным npm-кешем: чистая воспроизводимая установка по package-lock.
- `npm run lint`: ESLint, 0 ошибок и предупреждений.
- `npm run build`: успешная production-сборка, страницы статически сгенерированы.
- `npm run typecheck`: TypeScript без ошибок.
- `npm run test:e2e`: 6 из 6 тестов, 7.7 секунды. Использован установленный Chromium через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.
- `/`, `/kruzhok`, `/bible`: HTTP 200; нет ошибок консоли и необработанных ошибок страницы.
- `/play`: HTTP 307, Location `https://www.wherefrombible.ru/`.
- Host `www.leninblock.ru`, путь `/bible`: HTTP 308, Location `https://leninblock.ru/bible`.
- `/easm`, `/work`, неизвестный маршрут: HTTP 404, рабочая ссылка на главную.
- Sitemap содержит ровно три публичные страницы; редирект и будущие кейсы отсутствуют.
- Индивидуальные canonical, title/description, Open Graph и PNG-изображения 1200×630, robots, SVG-иконка и favicon.ico проверены.
- Горизонтального скролла нет при 320, 390, 768, 1440 px на всех трёх страницах.
- Axe WCAG 2 A/AA и 2.1 AA: 0 нарушений на 390 и 1440 px для всех страниц.
- Клавиатурный переход к содержимому, видимый focus, внутренние ссылки и переходы между продуктами работают.
- Отсутствуют ссылки на приватные релизы; показан честный статус подготовки скачивания.
- Мобильные и десктопные скриншоты всех страниц созданы тестами; главная, обе продуктовые страницы и social-preview просмотрены визуально.
- Ручной обзор создаваемых файлов и поиск типичных шаблонов токенов/ключей не нашли секретов. Исходники продуктов и установщики отсутствуют в репозитории сайта.

На этапе проверки исправлены: ожидание нормализованного canonical главной в тесте и недостаточный контраст номеров карточек. После исправлений полный набор браузерных тестов прошёл.

## Границы проверки

- Автоматическая проверка доступности не заменяет ручную проверку со скринридером.
- Бинарники Кружка не запускались; подпись и безопасность установщиков не подтверждены. Публичного скачивания нет.
- Внешняя игра отвечает HTTP 200 после переадресации на www. Полный игровой сеанс не проверялся.
- Серверные редиректы и canonical проверены локально. Production Vercel, DNS и HTTPS на пользовательском домене не настроены из-за отсутствия авторизации/доступа.
- Требования перед распространением приложения и недостающие материалы описаны в CONTENT_SOURCES.md и DEPLOYMENT.md.
